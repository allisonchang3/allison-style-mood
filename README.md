# Allison · Chic · Classic · Simple

Personal style mood page + daily look log for Seoul.

## Open it

Double-click `index.html` (no server needed). The log loads from `looks-data.js`.

## Daily look fields

In `looks-data.js` (and mirror in `looks.json`):

- `date`, `weekday`, `weather` (`summary`, `temp`, `rain`), `occasion`
- `clothes`, `jewelry`, `shoes`, `hair`, `note`
- `celebrityRefs`: `[ { "name": "Suzy", "src": "images/.../suzy-1.jpg", "caption": "why it matches" }, ... ]`

Prefer **Suzy** and **Hyojin Kong** for celebrity refs; other celebs only as fallback.

Store images under `images/YYYY-MM-DD/` next to `index.html`.
